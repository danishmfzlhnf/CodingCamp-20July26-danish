# CodingCamp-20July26-danish

Repository kumpulan proyek aplikasi web Coding Camp Danish.

## Daftar Proyek

1. **[E-Commerce Storefront (Shopee-like Experience)](ecommerce-storefront/README.md)**
   - Halaman beranda e-commerce super-app modern dan dinamis dengan fitur Smart Search Bar, Auto-Rotating Carousel Banner, Shortcut Menu Grid, Flash Sale dengan live countdown timer, Klaim Voucher Wallet, Kategori Pilihan, dan Rekomendasi Produk bergaya *Infinite Scroll*.
   - **Teknologi:** HTML5, CSS3 Modern, Vanilla JavaScript (ES6+), Mobile-First Responsive Design.
   - **Lokasi Direktori:** [`ecommerce-storefront/`](ecommerce-storefront/)

2. **[Expense & Budget Visualizer](expense-budget-visualizer/)**
   - Aplikasi visualisasi anggaran keuangan dan pencatatan pengeluaran harian interaktif dilengkapi diagram Chart.js dan penyimpanan localStorage.
   - **Teknologi:** HTML5, CSS3, JavaScript, Chart.js.
   - **Lokasi Direktori:** [`expense-budget-visualizer/`](expense-budget-visualizer/)
